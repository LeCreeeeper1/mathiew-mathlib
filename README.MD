## MATH-IEW

A math python library I made because I was bored

Shipped with an example code

Includes:

- MathVector with some functions:
  - add
  - pop
  - sum 
  - average
  - length 
  - min
  - max
  - mean

- Numbers like:
  - pi
  - e
  - tau (2*pi)
  - phi
  - psi (1/phi)

- Fast way (I think) to divide by 2^n
- Fast way to square root a number
- Fast way to compute the nth fibonacci number
- Sin, cos, tan
